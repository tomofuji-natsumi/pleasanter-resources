色と文言の対応

色を「動作の意味」に結び付け、同じ意味の文言は同じ色にそろえる案です。紫・オレンジは現状の色のまま、文言だけ足しています。

迷いやすい文言の決め方

組一方もう一方
提出 / 送信承認フローに乗る → 提出（紫）単に相手へ渡す → 送信（オレンジ）
申請 / 依頼承認の判断を求める → 申請（紫）作業を求める → 依頼（オレンジ）
依頼 / 通知相手の対応が必要 → 依頼知らせるだけ → 通知（どちらもオレンジ）
発行 / 出力帳票などを新しく作って出す → 発行（ティール）既存のデータを取り出すだけ → 出力（水色。印刷を含む）
完了 / 確定作業を終える → 完了（ティール）入力内容を確定して残す → 確定・登録（黄緑）
完了 / 承認自分の作業を終える → 完了（ティール）他人の申請を確定する → 承認（紫）
取消 / 取り下げ自分の処理を取り消す → 取消出した申請を引っ込める → 取り下げ（どちらも暗灰。直前へ戻す動作にそろえる）
取消 / キャンセル実行済みの処理を取り消す → 取消（暗灰）これからの操作をやめる → キャンセル（淡灰）
差し戻し / 却下やり直しを求める → 差し戻し（オレンジ）断って終える → 却下（赤）
送信 / 再送信初回 → 送信失敗後や再依頼で同じ内容を送り直す → 再送信（どちらもオレンジ）
登録 / 下書き保存確定して残す → 登録（黄緑）確定せず途中で残す → 下書き保存（淡灰）
戻る / 閉じる画面遷移を伴う → 戻る（暗灰）ダイアログなどをその場で閉じる → 閉じる（淡灰）

発行と送信を1操作で行う場合は、主目的の側に合わせます（帳票を出すなら発行）。

色の割り当ては案です（再発行をティールにするか、提出・申請を紫にするかなど）。アイコン名は仮です。
