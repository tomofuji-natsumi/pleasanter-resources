# PDF生成用フォント 対応文字種

`font/NotoSansJP-Regular.woff2` は、Google Fonts配布の[Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP)（フルセット）から、`fonttools`の`pyftsubset`で必要な文字種のみを抜き出して軽量化したものです。

## 生成元

- 元フォント: `NotoSansJP-Regular_Original/NotoSansJP-Regular.ttf`（Google Fonts公式配布のNoto Sans JP フルセット）
- ツール: fonttools（`python -m fontTools.subset`、`NotoSansJP-Regular_Original/build_font.py`経由）

## ディレクトリ構成

```
font/
├── NotoSansJP-Regular.woff2          # PDF出力用サブセットフォント（本体）
├── NotoSansJP-Regular_Charset.md     # このドキュメント
└── NotoSansJP-Regular_Original/      # 再生成用の原本データ一式
    ├── NotoSansJP-Regular.ttf        # Noto Sans JP フルセット原本
    ├── OFL.txt                       # 原本のライセンス
    ├── joyo_jinmeiyo.txt             # 常用漢字+人名用漢字リスト
    ├── old_forms.txt                 # 常用漢字表 公式旧字体364字
    ├── replace_old_new.go            # old_forms.txt の抽出元データ
    └── build_font.py                 # サブセット再生成用スクリプト
```

## 対応する文字種

- ひらがな（ゐ・ゑ・〆・ゝ含む）
- カタカナ（ヰ・ヱ含む）
- 全角記号：句読点、カギ括弧、感嘆符（！）、疑問符（？）等
- 漢字：常用漢字＋人名用漢字（2,999文字）＋常用漢字表 公式旧字体（364文字）＋業務でよく使う追加文字（下記参照）
- 半角英数字・記号アルファベット（A〜Z、a〜z）、数字（0〜9）
- 一般半角記号（@, #, &, *, + 等）
- 丸数字（①〜⑳、およびそれ以上）、丸付きアルファベット（Ⓐ等）、㈱等の丸囲み記号
- ローマ数字
  - 大文字：Ⅰ、Ⅱ、Ⅲ 〜 Ⅻ
  - 小文字：ⅰ、ⅱ、ⅲ 〜 ⅻ
- 特殊な記号・環境依存文字
  - 単位・略号：℃、№、TEL、Å、㎡ 等
  - 矢印：←、↑、→、↓
  - 数学記号：±、×、÷、≠、≦、≧、∞、∴、√ 等
  - 図形・マーク：■、▲、▼、◆、○、◎、★、☆、♀、♂ 等

グリフ総数: 4,768 / ファイルサイズ: 約633KB

### ファイルサイズの推移

| 段階 | サイズ | グリフ数 |
|---|---|---|
| 当初のminoryorg配布版（丸数字等を含まず問題の原因だったもの） | 709KB | 3,596 |
| JIS第3・4水準を含めてフルセットから再構築した版 | 約2.06MB | 14,678 |
| JIS第3・4水準を除外した版 | 約1.19MB | 8,410 |
| **現行版（常用漢字+人名用漢字+旧字体+個別追加分）** | **約633KB** | **4,768** |
| （参考）元のフルセットNoto Sans JP（ttf） | 約5.2MB | 16,732 |

現行版は、フルセットのNoto Sans JPと比べて約88%、丸数字等を含めた直後の版と比べても約69%のファイルサイズ削減となっている。

### 個別に追加した文字（人名・地名等でよく使われる旧字体・異体字）

髙、𠮷、邉、邊、濵、濱、圓、寬、檜、峰、峯、﨑、塚、廣、萬、眞、榮、ゐ、ゑ、ヰ、ヱ、〆、ゝ、㈱、渕、鶯、舘、攪、蘆

### 除外した文字種

- **上記の漢字セットに含まれないJIS第二水準漢字の大半**（人名・地名用途以外の生物名・専門用語等、旧字体は個別追加分を除く）
  PDF生成のタイムアウト対策のため、使用頻度の低い漢字を除外し軽量化。実運用で不足する文字が見つかった場合は、`old_forms.txt`（常用漢字表の公式旧字体364字）または個別追加リストに追記して再生成する。

### 元フォント自体に含まれず対応できなかった文字

- **巖**（U+5DA9、巌の旧字体）
- **樋**（U+6A2F）

Noto Sans JP自体にグリフが存在しないため、サブセット化以前の問題で含められない。必要であればSource Han Sans等、別フォントへの差し替えを検討。

## 文字セットの内訳・出典

| 区分 | 文字数 | 出典 |
|---|---|---|
| 常用漢字＋人名用漢字 | 2,999 | [vaiorabbit/everyday_use_kanji](https://github.com/vaiorabbit/everyday_use_kanji)（`regular_use+personal_name_utf8.txt`） |
| 常用漢字表 公式旧字体 | 364 | [ikawaha/kanji](https://github.com/ikawaha/kanji)（`replace_old_new.go`の旧字体側） |
| 個別追加分（指定27字のうち、上記2つと重複しない新規分） | 16 | 業務でよく使われる人名・地名用漢字を個別に指定（`build_font.py`の`EXTRA_CHARS`） |
| 漢字 合計（重複除く） | 3,175 | 上記の和集合 |
| 記号・かな類（罫線除く、Unicodeブロック指定） | ― | 下記参照。範囲内の未定義コードポイントは実際のグリフ数に含まれない |

グリフ総数4,768のうち、漢字は3,175文字中フォントに実在するもの（巖・樋を除く全て）、残りが記号・かな類。

## 再生成する場合の対象Unicode範囲（記号・かな類）

```
U+0000-007F   半角英数字・記号
U+00A0-00FF   Latin-1補助（Å, ±, ° 等）
U+2000-206F   各種記号・句読点
U+2100-218F   №, ℡, ローマ数字
U+2190-21FF   矢印
U+2200-22FF   数学記号
U+2460-24FF   丸数字・丸付きアルファベット
U+25A0-25FF   図形記号
U+2600-26FF   記号・マーク
U+3000-303F   全角記号・句読点
U+3040-309F   ひらがな
U+30A0-30FF   カタカナ
U+3200-33FF   単位記号・丸囲み漢字等
U+FF00-FFEF   全角英数字等
```

※ `U+2500-257F`（罫線）は意図的に含めていない。

漢字部分は範囲指定ではなく、上記の出典データ（常用漢字＋人名用漢字＋公式旧字体）のコードポイント集合に、個別追加分を加えたリストを`--unicodes-file`で指定して抽出している。

## 文字が表示されない場合の対応

該当の文字が上記のセットに含まれていない場合、PDF出力時に空文字になる。`NotoSansJP-Regular_Original/build_font.py`の`EXTRA_CHARS`にコードポイントを追記し、再生成することで対応可能（元フォント自体にグリフが無い文字は追加しても反映されない）。

## 再生成方法

要 fonttools, brotli（`pip install fonttools brotli`）。

```bash
cd font/NotoSansJP-Regular_Original
python build_font.py
```

各ファイルの役割は「ディレクトリ構成」を参照。
